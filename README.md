# TabiPhrase

旅行先で使う必須フレーズを表示する、軽量なWebアプリです。

## 起動方法

Python 3 がインストールされている環境で、プロジェクトフォルダから実行します。

```powershell
python server.py
```

PC上ではブラウザーで <http://127.0.0.1:8000> を開いてください。スマホなど別の端末からは、PCのVPN側IPアドレスを使って `http://<PCのVPN側IP>:8000` を開きます。Windowsファイアウォールで遮断される場合は、プライベートネットワーク上のTCPポート8000（必要なら8001も）への受信を許可してください。

停止するには起動したターミナルで `Ctrl+C` を押します。

ポートを変更する場合は、PowerShellで `$env:PORT=8080` を設定してから `python server.py` を実行します。

## Dockerで起動

Docker Desktopを起動して、プロジェクトフォルダから実行します。

```powershell
docker compose up -d --build
```

コンテナはホストの8001番で公開されます。停止は `docker compose down`、ログ確認は `docker compose logs -f` です。

## 機能

- 英語、フランス語、スペイン語、ロシア語、韓国語、簡体字中国語、台湾華語（繁体字）、タイ語、ウズベク語、日本語の表示切り替え
- 日本語と英語を常に併記し、選択した言語も追加表示
- 基本、交通、空港、税関、両替、ホテル、食事、買い物、緊急時のカテゴリー
- 税関でよく聞かれる質問と回答例（日数・宿泊先などの置き換え欄付き）
- 日本語と翻訳文を使った検索
- お気に入りの保存（ブラウザー内）
- 音声読み上げとフレーズのコピー
